# Arm IK naturalness: pronation redistribution and joint shear

Date: 2026-10-21. Status: **PLANNED — evidence complete, red test next, fix pending user-visible headset qualification.**

Live symptom: the upper arm and forearm "do not rotate naturally"; the mesh
twists and pinches at the joints and inside the forearm itself. The previous
clavicle-share/twist-pivot changes did not resolve it.

## 1. Native evidence (all measurements from captured native poses, not guesses)

GhidraMCP 7.0.0 (GUI, `http://127.0.0.1:8089`, program `DarkSoulsRemastered.exe`
from `DSRFull`) traced the pose pipeline: `FUN_140357a20` (PlayerIns vtable
+0xA8, the detour target) -> `FUN_140320980` -> `FUN_140379f70` ->
`FUN_140435d10` copies per-bone 48-byte model-space entries (`FUN_140209a70`
composes each via quaternion->mat3 in `FUN_1408e06b0` + constant quaternion
corrections). There is **no parent multiplication in the writer**: each MdlMtx
entry is final model space, animation-hierarchy-baked, and the GPU consumes it
directly through the bone palette. Post-animation model-space deltas on these
final matrices (our whole approach) are therefore conventionally safe.

## 2. Root causes (evidence-backed, ranked)

1. **`OrientModelHandPose` shears the authored twist pairs.** It rotates the
   Forearm subtree by the full wrist pronation angle about the elbow and only
   **half** that angle into ForeTwist about its own origin. Authored ForeTwist
   axial deviation never exceeds ~6 deg; a 90 deg controller pronation forces
   45 deg relative twist inside the AM forearm skin -> the reported forearm
   mesh twist/pinch "within the forearm itself".
2. **Full pronation lands as hand-vs-forearm axial shear.** The hand subtree
   receives only the wrist delta about the wrist, so the whole pronation also
   appears as hand twisting against the Forearm blend at the wrist joint ->
   joint pinch.
3. **`FromTo` aim parallel-transports the UpperArm basis.** The authored
   convention anchors UpperArm col 2 exactly along the elbow bend direction
   (|dot| = 1.000, 64/64 samples). Shortest-arc aiming ignores this, letting
   the upper-arm roll exceed the ~6 deg authored clavicle<->UpperArm tolerance
   -> armpit/BD torso mesh twist and an unnatural whole-arm roll look. This is
   gated by a hinge-consistency assertion; it is fixed only if it measures red
   after (1)+(2).

Legs reuse `SolveModelArmPose` (correct twist handling) and show no complaint;
the defect is arm-only in `OrientModelHandPose`, isolating the fault.

## 3. Fix design

In `OrientModelHandPose` (with `fore_twist` supplied):

- Pronation `P` (the twist component of the hand basis delta about the current
  elbow->wrist axis) is applied as **one identical rotation about the elbow**
  to the Forearm subtree **including the hand subtree**, and to the ForeTwist
  subtree. The wrist origin lies on the axis, so it does not move. Because
  Forearm and ForeTwist receive the exact same rotation, their authored
  relative pose is preserved exactly, and pronation becomes natural whole-
  forearm-below-elbow axial rotation (like native animation).
- The hand subtree then receives only the **swing (twist-free) remainder**
  `S = BasisRotation(pronated hand basis -> target basis)` about the wrist, so
  hand<->Forearm keeps pure wrist flexion; grip orientation is met exactly
  (`S*P` = full delta).
- `twist_skin` half-angle path is deleted. The `fore_twist == -1` path is
  unchanged.

Conditional phase 2 (only if the hinge assertion is red): aim the UpperArm
basis with a hinge-anchored rotation (col 0 along solved upper direction,
col 2 along the solved elbow bend normal) instead of `FromTo`, arm path only
(`SolveModelArmPoseWithClavicle`), legs untouched.

## 4. Red-capable test plan

`tests/test_arm_ik_naturalness.cpp` (CTest `arm_ik_naturalness`), driving the
production path `ArmPoseWristForGrip -> SolveModelArmPoseWithClavicle ->
OrientModelHandPose` on a rig built from run-7 sample 0 real idle matrices and
the real 80-entry parents (generated include `tests/native_idle_pose.inc`;
indices 23/24/25/26/36/38/39 L, 40/41/42/43/53/55/56 R):

- T1 pronation-in-place: hand target rolled 0->90 deg about the native
  elbow->wrist axis, wrist held. Assert per frame:
  |d ForeTwist<->Forearm axial| <= 6 deg (native bound), |d hand<->Forearm
  axial| <= 15 deg, |d UpperArmTwist<->UpperArm axial| <= 5 deg, grip
  orientation met exactly, wrist origin within 1 mm of target.
- T2 closed-loop 0.5 s circular wrist sweep (90 Hz) + T3 cross-body/overhead:
  link lengths exact (0.282/0.232 m, 1e-4), per-frame basis delta of every arm
  bone <= 12 deg (native max 2.5 deg).
- Hinge consistency: |dot(solved UpperArm col 2, solved elbow bend normal)|
  >= cos 30 deg during all trajectories (native: 1.000).

Expected red on current code: T1 axial-shear bounds (45 deg / 90 deg vs 6/15).
Green regression: link lengths, per-frame deltas, twist-pair upper arm.
