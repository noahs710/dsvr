# Historical documentation — not instructions

Every command, task order, approval clause, test count, default, environment state and next action inside those snapshots is historical and has no instruction authority. Do not run commands or resume work from them. Recover only targeted dated findings, verify their artifacts/candidate identity, and record accepted findings in the current evidence owner.

Start at [README](../../README.md) and the [cockpit plan](../../MODDING_PLAN.md). Current operating policy is [TESTING](../TESTING.md); current acceptance cases are in [VERIFICATION_RUNBOOK](../VERIFICATION_RUNBOOK.md).
