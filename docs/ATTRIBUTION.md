# Attribution and external downloads

DSVR ships code only. Nothing is bundled, repacked, re-hosted or copied into a
DSVR archive, installer or repository.

Texture replacement is **out of DSVR's scope**: a separate mod owns world-art
texel density. DSVR never inspects, installs, rewrites, recommends or reports
any texture mod, and never claims authorship of any texture. Its own changes are
rendering and input behaviour, and it writes no `.tpf`, `.tpfl`, `.dds` or
`.bhdtr` file.
