# Attribution and external tools

Texture replacement is **out of DSVR's scope**. DSVR's package builder rejects
common game and texture asset formats; the mod archive must contain no game
art, saves or extracted data. DSVR's own source and notices are separate from
Dark Souls: Remastered and its assets.

The optional launcher currently exposes third-party FPS Unlock installation
and a texture-tools download action. Those actions do not make the external
tools part of DSVR or authorize copying their files into its archive. Check
the selected tool's publisher, license, version and download destination
before distributing a launcher package.

Third-party code and licenses included with a DSVR build are listed in the
packaged `THIRD_PARTY.md` and `licenses/` directory. The game belongs to
FromSoftware and Bandai Namco.

Combat parameter terminology was informed by the [Souls Modding Wiki's
Dark Souls: Remastered reference](https://www.soulsmodding.com/doku.php?id=ds1r-refmat:main).
Its page states that wiki content is CC Attribution-Share Alike 4.0 except
where otherwise noted. The wiki is a research reference, not a native runtime
contract or a source of game files for the package.
